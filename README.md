VK бот для показа расписания БТИ АлтГТУ.
Парсит сайт института, хранит данные в SQLite, отвечает на команды.

Возможности:
- Парсинг расписания сайта АлтГТУ 
- Сохранение расписания в локальную БД sqlite
- Форматтер, оформляющий данные из бд в человекочитаемый вид
- Функциональный асинхронный VK бот, показывающий расписание на текущий и следующий дни, а также на текущую или следующую недели в зависимочти от дня недели

Схема работы:
parser_run -> parser -> database.db (сохранение в бд) - вручную, либо с определённой периодичностью через crontab
vk.bot -> database.db (чтение из бд, запись статистики) -> formatter -> пользователь

Команды бота:
- "Начать" - начать работу (работает как от пользователя, так и от евента вк кнопки)
- "start", "Start" - посмотреть описание бота и список команд
- "Tomorrow", "tomorrow", "tm", "Tm" - получить расписание на завтра
- "Today", "today", "td", "Td" - получить расписание на сегодня
- "week", "wk", "Wk", "Week" - получить расписание на неделю
    -- С понедельника по пятницу week показывает текущую неделю, в субботу и воскресенье уже следующую
- "Change", "change", "cg", "Cg" - сменить группу, на которую показывается расписание
- "Stat", "stat" - (для админа) показать статистику использования бота

Используемый стек:
- Python 3.12
- Sqlite
- Beautifulsoup4 4.15
- Vkbottle 4.11 (+ vkbottle-types)
